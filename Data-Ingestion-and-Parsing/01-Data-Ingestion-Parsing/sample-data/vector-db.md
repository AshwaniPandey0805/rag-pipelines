# Vector Databases in Modern RAG

Vector databases store data as high-dimensional mathematical vectors (embeddings) rather than scalar values.

## Key Capabilities
- **Approximate Nearest Neighbor (ANN)**: Searches billions of vectors in milliseconds.
- **Distance Metrics**: Cosine Similarity, Dot Product, and Euclidean Distance.
- **Hybrid Search**: Combining dense vector search with sparse keyword search (BM25).
